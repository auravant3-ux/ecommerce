# COLO SHOP - Premium E-Commerce Website

A modern, high-performance, and responsive fashion e-commerce storefront with smooth animations and interactive systems.

---

## 📦 Package Contents

- **`index.html`**: Main storefront (Hero, Categories, Filterable New Arrivals, Deal of the Week countdown timer, Best Sellers, Value props, Newsletter, Footer).
- **`lookbook.html`**: Interactive editorial lookbook with clickable "Shop The Look" hotspot pins and seasonal color palette moodboards.
- **`about.html`**: Brand heritage, three core pillars, and milestone timeline.
- **`blog-post.html`**: Sartorial trends journal with inline product highlights and live comment system.
- **`css/style.css`**: Complete design system, responsive breakpoints, transitions, and keyframe animations.
- **`js/app.js`**: Reactive Cart drawer, shipping progress meter, Quick View modal, real-time countdown timer, live search overlay, and wishlist manager.
- **`assets/images/`**: 13 high-resolution studio photographs and product imagery.

---

## 🚀 How to Run Locally

### Option 1: Direct File
Double-click `index.html` to open it directly in any browser (Chrome, Edge, Firefox, Safari).

### Option 2: Local Web Server
If you want to run it via local server:
- **PowerShell**: Run `./serve.ps1` to start a local server at `http://localhost:8080/`.
- **VS Code Live Server**: Right-click `index.html` and select **"Open with Live Server"**.

---

## 🌐 Deployment

This is a standalone, production-ready static website with zero dependencies or build steps required. You can deploy it instantly by dragging and dropping this folder onto:
- **Netlify**: [netlify.com/drop](https://app.netlify.com/drop)
- **Vercel**: `vercel deploy` or import repo
- **GitHub Pages**: Push to repository and enable GitHub Pages in Settings.
